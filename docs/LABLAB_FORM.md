## Long description

~~~
Small cross-border sellers lose margin when they negotiate factory quotes alone, or pay a sourcing agent a commission. TradeFlow is a prototype: one operator, a one-step offer model that sets the price, an optional AMD-hosted model that only reads a quote and phrases the reply, and a human who sends the offer. No factory deal has closed. No revenue is claimed. Umbrellas (HS 6601) are the demo wedge. Other codes use the same UN Comtrade preview route. A customs figure is reference only and does not set the price.

The decision core does not ask a language model what to pay (src/engine/solver.py, src/engine/multi_solver.py). With AMD live mode on and VLLM_BASE_URL and VLLM_MODEL unset, quote reading uses the AMD tokenfactory and Gemma-4-31B-IT. The committed log is Qwen3.8-Flash-Next in results/real_llm_benchmark_100.json: 348 calls, latency 16.81 s, cost $0.108444. No HTTP status is stored. python scripts/verify_amd_endpoint.py writes results/amd_endpoint_evidence.json. That file is generated by the script and is not committed unless present. status: ok means HTTP 200 on one short chat, not a quote extraction. skipped_no_credentials is not a successful check. No committed Gemma latency.

The auction headline is savings versus the first-round best quote. Versus target stays visible, including when that figure is negative. Savings versus the walk-away ceiling are secondary. Self-play (results/self_play_benchmark.md, 20 matches x 5 archetypes, 100 matches, seed 42) runs from 8.8% to 20.0% versus that table's walk-away ceiling. Against a Hard-Bargainer, 8.8% versus a fixed baseline's 9.2%. The real-model log closed at 61.11% of completed matches against a Bluffing Hardliner, with 0 budget violations in 94 completed matches. Held-out intent accuracy is 63.08% (195 of 500 held out). results/bench.json is a CPU measurement (is_gpu_active: false).

The desk runs offline until AMD live mode is on and VLLM_API_KEY is a real secret. The model never sets our price.
~~~
